# Changelog

## [1.0.0] - 2026-09-26

### Added

- Project skeleton with modular package structure
- ScopeGuard -- mandatory authorization boundary
- CLI: scope, config, tools, status, pipeline
- ASCII banner with UTF-8 support and --no-color
- Typed exceptions mapped to documented exit codes
- Finding and Target dataclasses
- External tool detection (bhairava tools)
- Scope YAML schema + example
- Pytest suite covering Scope Guard edge cases
- install.sh / uninstall.sh for Kali / Debian
- Packaging via pyproject.toml
