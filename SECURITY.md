# Security Policy

## Authorized use only

BHAIRAVA-BB is for authorized security testing. By using it you confirm you
have explicit written permission for every target you test.

## Reporting a vulnerability in BHAIRAVA-BB

Open a private security advisory on the repository. Do not open public
issues for security bugs.

## What we fix

- Scope Guard bypasses
- Command-injection risks in tool wrappers
- Credential leaks in generated reports
- Unsafe subprocess construction
